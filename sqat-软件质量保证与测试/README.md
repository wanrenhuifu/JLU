# 软件质量保证与测试

## 项目简介

本项目是吉林大学**软件质量保证与测试（SQAT）**课程的结课大作业。收录了课程中的 32 个测试案例题目，涵盖黑盒测试、白盒测试、等价类划分、边界值分析、决策表、因果图、状态转换等多种软件测试技术与方法。每个案例均包含题目描述、测试需求分析与测试用例设计。

## 注意事项

- 文档图表使用 Mermaid 语法渲染
- 课程文档中已去掉学生分组信息表，防止泄露隐私
- 本项目为测试案例文档集，不包含代码实现。

## 技术栈

- **文档格式**：Markdown
- **图表绘制**：Mermaid
- **文档转换**：markitdown
- **文档编辑**：Typora（推荐）
- **版本控制**：Git

## 功能特性

本案例集覆盖以下测试技术领域：

| 技术领域 | 代表案例 |
|:---------|:---------|
| 等价类划分与边界值分析 | NextDate 函数、三角形问题、日期设置 |
| 决策表测试 | 电话账单、佣金问题、机票定价 |
| 因果图与判定表 | 自动售货机、字符属性、状态显隐 |
| 状态转换测试 | 个人认证、网购流程、信息查询系统 |
| 场景法 / 用例测试 | ERP 系统、学生选课、工资管理 |
| 白盒测试 / 路径覆盖 | 简单小程序、加法计算器 |
| 逻辑推理与组合测试 | 最佳找零钱、安排工作、象棋跳马 |

## 使用说明

建议使用 Typora 或支持 Mermaid 渲染的 Markdown 编辑器查看项目文档，以获得最佳阅读体验。

### 推荐阅读顺序

1. 先查看 `2026-SQAT-实验报告提交要求.pptx` 了解报告规范
2. 按编号顺序阅读各案例题目文档
3. 注意案例中涉及的 Mermaid 图表需要相应编辑器支持渲染
