【案例主题】黑盒测试方法—边界值分析法

【案例题目】05-最佳找零钱

【案例目标】

以找零钱最佳组合的测试用例设计为例，学习边界值分析法的使用方法。

【案例内容】

假设商店商品价格[X]皆不大于100元（整数），若顾客买一件商品，付款[Y]在100元内（含100元），求找给顾客的最少货币张数？

货币面值：

50元[R50]

20元[R20]

10元[R10]

5元[R5]

2元[R2]

1元[R1]

【案例作业步骤】

1、分析输入/输出条件

（1）分析输入条件

商店商品价格[X]不大于100元，由此可知X的取值范围为？

A.0≤X≤100

B.0<X≤100

C.0≤X<100

D.0<x<100

|  |  |
| --- | --- |
| 你的答案： | B |

顾客付款[Y]在100元内并且Y应该大于等于X，由此可知Y的取值范围为？

A.X≤Y≤100

B.X<Y≤100

C.X≤Y<100

D.X<Y<100

|  |  |
| --- | --- |
| 你的答案： | A |

经过上面的分析已经找出X和Y的范围，对X、Y划分等价类，完成表1-1。

2、确定边界值测试方法

边界值的取值原则有一般边界值、健壮性边界值、最坏边界值、健壮性最坏情况边界值测试法，本题选择健壮性最坏情况边界值测试方法为输入数据的无效边界设计测试用例，采用一般边界值测试方法为输出数据设计测试用例。
