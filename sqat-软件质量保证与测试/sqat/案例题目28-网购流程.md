【案例主题】灰盒测试—场景法

【案例题目】28-网购流程

【案例目标】

以网购流程的案例为例，学习使用场景法设计测试用例的方法。

【案例内容】

用户进入网上购物网站进行购物，这时需要登录帐号，选择商品，设置订单，确认后付款，最后生成订单，完成此次购物。

我们通过这个购物系统来学习场景法基本知识，并通过案例步骤理解场景法的案例操作步骤。

【案例作业步骤】

1、根据案例分析画出事件流示意图

登录网购系统需要输入用户名、密码。验证登录成功后可以浏览商品、设置订单，确认并付款成功后生成订单。生成订单即表示整个网购活动成功。

设置订单时，如果库存不足可以重新设置订单或重新选择商品；付款时，如果账号余额不足，可以返回浏览商品；生成订单后，还可以返回浏览商品，继续购物；另外，登录不成功或遇到库存不足、账号余额不足的情况也可以直接退出登录。

请根据上面的描述，打开画图工具，画出事件流示意图，然后将其截图，保存为（.jpg）格式，再粘贴到下方。

答案：

**下图采用Mermaid流程图(flowchart TD)绘制，自上而下展示网购系统的基本流和10个备选流。矩形节点表示流程步骤，菱形节点表示判断条件，虚线箭头表示备选流的分支路径。**

```mermaid
flowchart TD
    %% 定义节点
    Start(["开始"]) --> Login["1. 登录账号<br/>输入用户名和密码"]

    Login --> CheckUser{"验证用户名"}

    %% 用户名相关分支
    CheckUser -->|"用户名正确"| CheckPwd{"验证密码"}
    CheckUser -.->|"备选流3:<br/>用户名错误<br/>直接退出"| Exit1(["退出系统"])
    CheckUser -->|"备选流1:<br/>用户名错误<br/>返回重新登录"| Login

    %% 密码相关分支
    CheckPwd -->|"密码正确"| Browse["2. 浏览/选择商品"]
    CheckPwd -.->|"备选流4:<br/>密码错误<br/>直接退出"| Exit2(["退出系统"])
    CheckPwd -->|"备选流2:<br/>密码错误<br/>返回重新登录"| Login

    %% 设置订单
    Browse --> SetOrder["3. 设置订单<br/>选择购买数量"]
    SetOrder --> CheckStock{"检查库存"}

    %% 库存相关分支
    CheckStock -->|"库存充足"| PayConfirm["4. 确认付款"]
    CheckStock -.->|"备选流6:<br/>库存不足<br/>直接退出"| Exit3(["退出系统"])
    CheckStock -->|"备选流5:<br/>库存不足"| HandleStock{"处理方式"}
    HandleStock -->|"重新设置订单"| SetOrder
    HandleStock -->|"备选流7:<br/>重新选择商品"| Browse

    %% 付款相关分支
    PayConfirm --> CheckBalance{"检查账号余额"}
    CheckBalance -->|"余额充足"| GenOrder["5. 生成订单"]
    CheckBalance -.->|"备选流9:<br/>余额不足<br/>直接退出"| Exit4(["退出系统"])
    CheckBalance -->|"备选流8:<br/>账号余额不足"| Browse

    %% 生成订单后
    GenOrder --> Success["购物成功<br/>交易完成"]
    Success -.->|"备选流10:<br/>继续购物"| Browse

    %% 样式定义
    style Start fill:#E8F5E9,stroke:#2E7D32,stroke-width:2px
    style Login fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style Browse fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style SetOrder fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style PayConfirm fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style GenOrder fill:#E3F2FD,stroke:#1565C0,stroke-width:2px
    style Success fill:#E8F5E9,stroke:#2E7D32,stroke-width:2px
    style CheckUser fill:#FFF3E0,stroke:#E65100,stroke-width:2px
    style CheckPwd fill:#FFF3E0,stroke:#E65100,stroke-width:2px
    style CheckStock fill:#FFF3E0,stroke:#E65100,stroke-width:2px
    style CheckBalance fill:#FFF3E0,stroke:#E65100,stroke-width:2px
    style HandleStock fill:#FFF3E0,stroke:#E65100,stroke-width:2px
    style Exit1 fill:#FFEBEE,stroke:#C62828,stroke-width:2px
    style Exit2 fill:#FFEBEE,stroke:#C62828,stroke-width:2px
    style Exit3 fill:#FFEBEE,stroke:#C62828,stroke-width:2px
    style Exit4 fill:#FFEBEE,stroke:#C62828,stroke-width:2px
```

**上图说明：** 事件流示意图展示了网购系统的完整流程。蓝色矩形表示基本流的5个主要步骤；橙色菱形表示关键判断节点；绿色矩形表示流程起点和成功终点；红色圆角矩形表示退出终点；虚线箭头表示10个备选流的分支路径。基本流为：登录账号→选择商品→设置订单→确认付款→生成订单（成功结束）。
