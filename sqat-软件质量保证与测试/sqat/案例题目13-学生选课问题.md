【案例主题】黑盒测试方法—错误推测法

【案例题目】13-学生选课问题

【案例目标】

通过"学生选课问题"案例学习采用错误推测法设计测试用例。

【案例内容】

1 登录页面

（1）登录页面包含登录名、登录密码、验证码和登录按钮。

（2）系统分配三个已知用户。分别是：

①登录名：Student1 密码：123abc

②登录名：Student2 密码：456abc

③登录名：Student3 密码：789abc

（3）提示信息

①当登录名为空时，系统提示"请输入登录名!"；

②当密码为空时，系统提示"请输入密码!"；

③当验证码为空时，系统提示"请输入验证码!"；

④当登录名或密码错误时，系统提示"登录名/登录密码输入不正确!"；

⑤当验证码输入错误时提示"验证码输入不正确!"；

⑥登录名、密码、验证码全部填写正确,成功登录系统。

2 选课页面

（1）选课页面有三部分构成，分别为：显示登录名和实现注销功能，实现查询功能，显示课程信息列表。

（2）学生登录后，进入到选课页面。会在右上角显示登录名，和注销链接；学生点击注销链接，返回到登录页面。

（3）学生可通过课程名、教师名查询相应课程，查询功能实现模糊查询。

（4）选课页面中课程信息列表有课程号、课程名、学分、教师名、查看链接这五个字段；学生点击查看链接，会进入到课程详细信息页面。

（5）课程详细信息页面显示教师名、学时、地点、时间、总人数、已申请人数等信息。

（6）在课程详细页面中点击"返回"按钮，返回选课页面。

2、采用错误推测法补充可疑测试用例

（1）列举程序中所有可能出现的错误和容易发现错误的地方

列举程序中所有可能出现的错误和容易发现错误的地方，填入表2-1。

表2-1

|  |  |
| --- | --- |
| 编号 | 可能出现错误和容易发现错误的地方 |
| 1 | 登录名输入SQL注入特殊字符（如单引号、分号、--注释符等） |
| 2 | 用户名或密码前后包含空格，系统未做Trim处理 |
| 3 | 密码输入超长字符串（如超过系统限制长度）导致缓冲区溢出或异常 |
| 4 | 验证码过期后仍被提交验证，系统未校验时效性 |
| 5 | 多个用户或设备同时登录同一账号，系统未处理并发登录冲突 |
| 6 | 未登录直接在浏览器地址栏输入选课页面URL，试图绕过登录验证 |
| 7 | 登录成功后点击浏览器后退按钮，系统未正确控制会话状态 |
| 8 | 查询功能中输入XSS攻击脚本（如<script>alert('xss')</script>） |
