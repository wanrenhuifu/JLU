# JAVA 程序设计

## 项目简介

本项目是吉林大学**JAVA 程序设计**课程的作业，要求实现一个简易的 MUD（Multi-User Dungeon）多人文字游戏，包括服务端和客户端两部分。

## 技术栈

- **语言**：Java
- **网络通信**：Socket
- **数据存储**：数据库 / XML / 文件

## 功能特性

### 基本功能

- 同时支持多人在线游戏
- 创建虚拟游戏世界
- 玩家可在虚拟世界中移动（w, e, s, n, ne, se, nw, sw, u, d）
- 玩家动作（连线、移动）对同房间其他玩家可见
- 基本动作：查看（look / l）、退出（quit）
- 玩家账户信息持久化存储（数据库或文件）

### 可扩展功能（选做）

- 物品系统（get / drop）
- 群聊（chat）与私聊（tell），查看在线玩家（who）
- 游戏世界信息存储于数据库或 XML 文件
- NPC 随机走动与玩家交互
- 武功系统与打斗
- 玩家状态（hp）持久化
