一. 论述题（共1题，100分）
1. (论述题, 100分)
实现一个简易的MUD游戏开发，包括服务器端和客户端两部分内容

相关参考资料已上传学习通资料“课程Mud游戏开发.zip”

一、基本要求：

1.同时支持多人在线游戏(15)；

2.创建一个虚拟的世界(10)；

3.玩家可以在虚拟世界中移动(15),方向(w,e,s,n,ne,se,nw,sw,u,d)；

4.玩家的动作（包括连线、移动）对其他相关玩家（同一房间）可见(15)；

5.玩家的基本动作包括，查看(look,l)，退出(quit)(10)；

6.玩家账户信息存储在数据库或文件中（第一次登陆创建账户）(15)

7.客户端能够建立与服务器的链接、向服务器发送消息，接受并显示信息(10)。



二、可扩展内容（任选其中一个或多个）：

1.实现一个物品，该物品可以被get和drop，只能被一个玩家持有，被get后其他人不能看到；

2.实现群聊chat 功能，实现私聊tell功能，能够查看在线玩家(who)；

3.将创建的游戏世界信息在数据库或XML文件存储，设计合理的结构；

4.实现一个NPC，可以随机在游戏世界中走动，可以和玩家交互；

5.实现一项武功，用户能够获得武功并存储相关信息，能通过武功进行打斗；

6.实现玩家状态信息，可以查看(hp)，并能够存储玩家状态(退出后记录当前状态，下次登录后以当前状态连线)；

7.其他有趣或感兴趣的功能（难度同上面6点）。



三、评分标准：

1.实现基本要求内容90分

2.扩展内容每项5分，满分100分

3.鼓励尽可能完成多的扩展功能

4.评分时参考以下原则

（1）功能全部完成，且代码结构清晰、优美给满分。

（2）功能全部完成，代码实现上臃肿、结构不清晰，每项减1分。

（3）功能未完成扣相应分项分数。



四、提交内容：

提交压缩文件，命名“学号_姓名.rar”，包括源代码和报告。
实验报告一份，提交电子版和纸质版(格式不限，但写清如下内容)
写清学号、姓名、和实现的功能；
系统分模块，画出每个模块的类图，并简要解释类、属性及方法的作用；
按功能，给出实现的界面效果。
