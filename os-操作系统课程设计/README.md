# 操作系统课程设计

## 项目简介

本项目是吉林大学**操作系统课程设计**（544004）作业，基于 TypeScript + Vite 构建的统一 Web 模拟实验平台。平台整合了操作系统课程中的 10 个经典模拟实验，采用温暖的浅色 UI 设计，支持动态可视化与交互式操作，帮助直观理解操作系统的核心原理与算法。

## 注意事项

- 实验数据在页面刷新后会重置，建议截图保存重要结果
- 推荐使用 Chrome / Edge / Firefox 最新版浏览器访问
- 生产构建产物已输出至 `os-course-design/dist/`，可直接用浏览器打开 `index.html`

## 技术栈

- **构建工具**：Vite 6.x
- **开发语言**：TypeScript 5.x
- **前端技术**：原生 HTML5 / CSS3 / ES2020+
- **图形渲染**：Canvas 2D
- **样式方案**：CSS 自定义属性 + 现代化设计系统

## 功能特性

平台包含以下 10 个操作系统模拟实验：

| 编号 | 实验名称 | 核心内容 |
|:----:|:---------|:---------|
| 1 | CPU 调度：反馈排队算法 | 多级反馈队列（FB）调度模拟，支持多级就绪队列、时间片、I/O 请求 |
| 2 | 进程互斥：软件互斥算法 | Dekker / Peterson / Lamport / Eisenburg-Mcguire 四种算法模拟 |
| 3 | 死锁避免：银行家算法 | 安全性检测（递归实现所有安全序列）、资源请求试分配与回滚 |
| 4 | 死锁检测：资源分配图约简 | 图输入、Canvas 绘制、约简过程动画、死锁判定 |
| 5 | 页面置换：工作集模型 | FIFO / LRU / NUR / CLOCK 四种算法，逻辑地址→物理地址转换 |
| 6 | 读者写者：写者优先 | 信号量 P/V 操作同步，写者优先策略，动态进程状态显示 |
| 7 | 消息通信：缓冲技术 | 缓冲池链表管理、消息链、发送/接收进程并发模拟 |
| 8 | 磁盘调度：引臂调度算法 | FCFS / SSTF / SCAN / LOOK，磁头移动可视化、时间参数计算 |
| 9 | 反置页表：杂凑页式管理 | Hash 函数 + 顺序探测冲突解决、地址转换、十六进制显示 |
| 10 | 伙伴系统：内存分配释放 | 块组 0-9 空闲链表、分配拆分、释放合并、内存位图可视化 |

### 设计特点

- **统一界面**：左侧导航栏切换实验，右侧主内容区展示
- **温暖配色**：暖米白背景、珊瑚橙强调色、圆角卡片
- **动态可视化**：队列动画、Canvas 图形、状态高亮、单步/自动播放
- **响应式布局**：自适应不同屏幕尺寸

## 运行说明

### 开发模式

```bash
cd os-course-design
npm install
npm run dev
```

浏览器将自动打开 `http://localhost:5173`

### 生产构建

```bash
cd os-course-design
npm run build
```

构建产物输出到 `os-course-design/dist/` 目录，可直接用浏览器打开 `dist/index.html`。

### 直接运行

若已构建，可直接双击打开：

```
os-course-design/dist/index.html
```

### 浏览器兼容性

- Chrome / Edge / Firefox / Safari 最新版
- 支持 ES2020+ 的现代浏览器
