# 操作系统课程设计 - 实验模拟平台

一个基于 TypeScript + Vite 构建的统一 Web 应用，包含操作系统课程设计的 10 个模拟实验，采用 Claude 官网风格的温暖浅色 UI 设计。

## 技术栈
- **构建工具**: Vite
- **语言**: TypeScript 5.x
- **样式**: 原生 CSS 自定义属性 + 现代化设计系统
- **UI**: HTML/CSS + Canvas 2D

## 快速开始

### 开发模式
```bash
npm install
npm run dev
```
浏览器将自动打开 `http://localhost:5173`

### 生产构建
```bash
npm run build
```
构建产物输出到 `dist/` 目录，可直接用浏览器打开 `dist/index.html`。

## 包含的 10 个实验

| 编号 | 实验名称 | 核心内容 |
|------|---------|---------|
| 1 | CPU调度：反馈排队算法 | 多级反馈队列(FB)调度模拟，支持多级就绪队列、时间片、I/O请求 |
| 2 | 进程互斥：软件互斥算法 | Dekker / Peterson / Lamport / Eisenburg-Mcguire 四种算法模拟 |
| 3 | 死锁避免：银行家算法 | 安全性检测（递归实现所有安全序列）、资源请求试分配与回滚 |
| 4 | 死锁检测：资源分配图约简 | 图输入、Canvas绘制、约简过程动画、死锁判定 |
| 5 | 页面置换：工作集模型 | FIFO / LRU / NUR / CLOCK 四种算法，逻辑地址→物理地址转换 |
| 6 | 读者写者：写者优先 | 信号量P/V操作同步，写者优先策略，动态进程状态显示 |
| 7 | 消息通信：缓冲技术 | 缓冲池链表管理、消息链、发送/接收进程并发模拟 |
| 8 | 磁盘调度：引臂调度算法 | FCFS / SSTF / SCAN / LOOK，磁头移动可视化、时间参数计算 |
| 9 | 反置页表：杂凑页式管理 | Hash函数+顺序探测冲突解决、地址转换、十六进制显示 |
| 10 | 伙伴系统：内存分配释放 | 块组0-9空闲链表、分配拆分、释放合并、内存位图可视化 |

## 项目结构
```
os-course-design/
├── index.html              # 主页面入口
├── package.json
├── vite.config.ts
├── tsconfig.json
├── dist/                   # 构建输出（可直接部署）
└── src/
    ├── main.ts             # 应用入口
    ├── app.ts              # 主框架：侧边栏导航、实验懒加载
    ├── styles/             # 全局CSS设计系统
    ├── common/             # 公共组件（UI工具、队列/表格渲染、Canvas辅助）
    └── experiments/        # 10个实验模块
```

## 设计特点
- **统一界面**: 左侧导航栏切换实验，右侧主内容区展示
- **Claude风格配色**: 暖米白背景、珊瑚橙强调色、圆角卡片
- **动态可视化**: 队列动画、Canvas图形、状态高亮、单步/自动播放
- **响应式布局**: 自适应不同屏幕尺寸

## 浏览器兼容性
- Chrome / Edge / Firefox / Safari 最新版
- 支持 ES2020 的现代浏览器
