# JLU 课程作业合集

吉林大学软件工程专业课程作业整合仓库，汇集本科期间各门课程的作业、课程设计和大作业项目。

## 目录

| 目录 | 课程 | 说明 |
|:---|:---|:---|
| [`oop-面向对象程序设计`](./oop-面向对象程序设计) | 面向对象程序设计（C++） | 模拟即时通信系统课程设计 |
| [`java-JAVA程序设计`](./java-JAVA程序设计) | JAVA 程序设计 | MUD 游戏开发（服务端+客户端） |
| [`uml-统一建模语言`](./uml-统一建模语言) | 统一建模语言及工具 | 教务管理系统 UML 建模大作业 |
| [`harmonyos-鸿蒙实训`](./harmonyos-鸿蒙实训) | 鸿蒙实训 | 鸿蒙应用开发项目，含组件学习与刷题 App |
| [`ml-机器学习`](./ml-机器学习) | 机器学习 | 房价预测、垃圾邮件分类、手写数字识别 |
| [`pr-模式识别`](./pr-模式识别) | 模式识别 | 课程作业（待补充） |
| [`os-操作系统课程设计`](./os-操作系统课程设计) | 操作系统课程设计 | 10 个 OS 经典算法 Web 模拟实验平台 |
| [`data-viz-数据可视化`](./data-viz-数据可视化) | 数据可视化 | 基于 OpenCV 的图像处理与可视化大作业 |
| [`qt-基于Qt的跨平台软件编程`](./qt-基于Qt的跨平台软件编程) | 基于 Qt 的跨平台软件编程 | EasyWord 文字处理软件 |
| [`sa-软件体系结构`](./sa-软件体系结构) | 软件体系结构 | 智能医疗问诊记录分析平台架构设计 |
| [`oracle-软件开发综合实践`](./oracle-软件开发综合实践) | 软件开发综合实践 | 图书管理系统（React 前端演示） |
| [`sqat-软件质量保证与测试`](./sqat-软件质量保证与测试) | 软件质量保证与测试 | 32 个软件测试案例集 |
